**Base FeeLast is live on mainnet.** Everything on this page is testnet, self-hosted devnet, or a local fork. The neat app groups the same list at `/lab`.

| Surface | Network | Status |
|---|---|---|
| FeeLast hook + AXIS/USDC + bid bot | Base `8453` | **Mainnet** — see [Uniswap v4 on Base](/docs/guides/uniswap) |
| Demo WETH → USDC fill | Sepolia | Testnet wallet fills |
| CompetitiveFeeHook (v4) | Sepolia | Initialized; not FeeLast |
| QuoteOracle + CRE curve | Sepolia | Curve on-chain; no settle path yet |
| LP revenue dashboard | Sepolia `eth_call` | Synthetic replay |
| Frame swap + Anon-RPC | EIP-8141 `1337` | Devnet proof |
| 1inch Aqua SwapVM opcode | Anvil fork | Fork only |

## Aqua SwapVM (fork)

CompetitiveFee Extruction inside SwapVM on a mainnet/Base Anvil fork. Sepolia has Aqua registry vanity addresses but no settle path for this app.

```sh
cd packages/swapvm-opcode
npm run aqua:fork
```
